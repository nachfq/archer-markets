# Security policy

Archer Markets is an unaudited, testnet-only proof of concept. Do not use it with
real assets or treat the repository, hosted frontend, simulations or local acceptance
evidence as a production security guarantee.

While the repository is private, report suspected vulnerabilities directly to the
repository owner through the existing private project channel. After publication,
use GitHub private vulnerability reporting once it is enabled. Do not publish secrets,
private keys, exploit details or affected wallet data in an issue. Non-sensitive
correctness reports may use the issue tracker.

The current security assumptions and known limitations are documented in
[`docs/research/security-review.md`](docs/research/security-review.md).
