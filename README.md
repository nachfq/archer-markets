# Archer Markets

Fully collateralized Stock Token options with an onchain orderbook.
Each option covers **one Stock Token** and holds the assets needed to fulfill it
in its own smart contract. Hold, resell or exercise manually before expiration;
there is no automatic exercise.

[Open the app](https://archer-markets.up.railway.app/) ·
[Documentation](https://nachfq.github.io/archer-markets/)

Five V4 markets on Robinhood Chain Testnet: TSLA, AMD, AMZN, NFLX and PLTR against
USDG. Test assets only; the contracts are unaudited.
